# github-practice

我的第一个 GitHub 练习仓库，用来熟悉提交、分支、Issue 和 Pull Request 的完整流程。

## 练习记录

- [x] 初始化本地仓库并写 README
- [ ] 开一个分支，改 README，发起第一个 Pull Request
- [ ] 用 Issue 记录一个待办，并在提交里引用它
- [ ] 加一个 GitHub Actions 工作流，让它自动运行
- [ ] 用 GitHub Pages 发布一个静态页面

## 常用命令

```bash
git status          # 看当前改了什么
git add .           # 把改动放进暂存区
git commit -m "..." # 记录一次提交
git push            # 同步到 GitHub
```
